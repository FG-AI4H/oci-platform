# For evaluation participants

You have a model, or a reader's answers, and you want to know how well they do on an evaluation task hosted on the OCI. You fill in a predictions file, check it, submit it for scoring and read the result. You can also declare the model the result is evidence for, so that a reviewer or a regulator can read the result against what the model is meant to do.

You need no technical background for any of this: a spreadsheet is enough.
