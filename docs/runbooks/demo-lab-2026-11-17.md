## If something goes wrong

| Symptom                        | Likely cause and fallback                                                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `check`: JWKS lists 0 keys     | The API couldn't reach KMS at boot (see the API log for "Passport signing key not ready"); restart the API task. Show B5 from the diagram.  |
| B3 shows a tier conflict       | The researcher's address isn't institutional (the `.invalid` demo address is not). The holder can still approve; say the verdict is a hint. |
| `seed`: 403 on create          | The holder isn't in the `host` group yet; sign out and in again after adding it, so the token carries the group.                            |
| B4: no mail after 2 minutes    | Use the signer link printed by `sign`.                                                                                                      |
| `submit --scored`: quota error | Three scored submissions this week already. Show the earlier result on the leaderboard.                                                     |
| Any token error                | Tokens expire after an hour. Copy a fresh one from `/api/auth/session`.                                                                     |
| Sign in returns the same user  | The Cognito hosted session is still open (#663). Open the pool's `/logout` endpoint (see #663), or use a second browser profile.            |
